# 🎯 Guess The Number Game

A simple and interactive number guessing game built using **HTML, CSS, and JavaScript**.

(Will be added after GitHub Pages deployment)

## 🎮 How to Play

- The computer generates a random number between **1 and 100**
- You have **5 attempts** to guess the correct number
- After each guess:
  - 📉 Too High
  - 📈 Too Low
  - 🎉 Correct!
- Score decreases with each wrong attempt
- Restart button appears after win or game over
